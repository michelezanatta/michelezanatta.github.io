Weather ETL Pipeline

End-to-end data pipeline that extracts weather data from a public API, stores it in DuckDB, and builds analytics-ready models with dbt. It can run on-demand or on a daily schedule via Prefect.

  • Tech: Python · DuckDB · Prefect · dbt
  • Focus: Data Engineering · ETL/ELT · Orchestration · SQL Transformations
Source code README

What it does

  • Extract weather data from Open-Meteo API
  • Transform raw data into clean, deduplicated datasets (Parquet)
  • Load into DuckDB using idempotent schema creation + upserts
  • Model with dbt (example: daily summary from hourly past table)
  • Schedule daily runs locally with Prefect (server + worker + deployment)

How to run (local)

These commands are meant to be executed from the ETL repository.

Pipeline scripts

poetry install
poetry env activate

# Extract (writes raw parquet)
python -m src.extract --local-store --output-path rsc/data/raw_data

# Transform (reads raw parquet, writes processed parquet)
python -m src.transform --input-path rsc/data/raw_data --local-store --output-path rsc/data/proc_data

# Create schema (idempotent)
python -m src.create_db --db-path data/weather.duckdb

# Load (upsert into DuckDB)
python -m src.load --db-path data/weather.duckdb --input-path rsc/data/proc_data

# Run the full pipeline
python -m src.pipeline --config config/pipeline.toml

Prefect scheduling (local)

# Terminal A
prefect server start

# Terminal B
export PREFECT_API_URL="http://127.0.0.1:4200/api"
prefect work-pool create local-pool --type process
prefect worker start --pool local-pool

# Create a scheduled deployment (interactive)
prefect deploy

dbt transformations

dbt reads from the DuckDB tables produced by the pipeline and builds analytics models (example: daily_summary). 

# Required because the dbt profile uses an env var
export DUCKDB_PATH="$(pwd)/data/weather.duckdb"

dbt --project-dir dbt/weather_dbt debug
dbt --project-dir dbt/weather_dbt run --select daily_summary

Quick check via Python:

python - <<'PY'
import duckdb
con = duckdb.connect("data/weather.duckdb", read_only=True)
print(con.execute("select * from daily_summary limit 10").fetchdf())
con.close()
PY

Docker

Run it as a one-shot container, or run Prefect server+worker via docker-compose.

One-shot pipeline run

docker build -t weather-etl .
docker run --rm \
  -v "$(pwd)/data:/app/data" \
  -v "$(pwd)/rsc:/app/rsc" \
  -v "$(pwd)/config:/app/config" \
  -e DUCKDB_PATH=/app/data/weather.duckdb \
  weather-etl

Prefect in docker-compose

docker compose up --build

# one-time: create the pool
docker compose run --rm runner prefect work-pool create local-pool --type process

# run once
docker compose run --rm runner

# deploy (interactive)
docker compose run --rm runner prefect deploy
