DQ EDA Copilot

About the project

This project focuses on deterministic exploratory data-quality analysis for tabular datasets. It profiles the uploaded file, detects issues such as missingness, duplicates, constant columns, outliers, and correlations, computes a heuristic quality score, and produces a concise natural-language summary.

Demo modes

The public web demo runs with a deterministic interpretation fallback so the application can stay free to host and consistently available online.

In local developer mode, the backend can be configured to call a locally hosted open-source model via Ollama exactly once per analysis, enabling a fully local LLM-assisted interpretation workflow.

  • Backend: FastAPI, pandas, pyarrow, Jinja2
  • Frontend: Static GitHub Pages page with JavaScript integration
  • LLM mode: local OSS model or deterministic fallback
  • Output: JSON analysis + downloadable HTML report
